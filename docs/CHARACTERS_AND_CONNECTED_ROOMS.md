# ตัวละคร 5 อาชีพและดันเจี้ยนเชื่อมต่อกัน

> **อัปเดต 2026-10-17:** เปลี่ยนตัวละครเป็น pixel sprite มุม 3/4 top-down ใน `src/game/PixelSprites.ts` แล้ว Sword เป็นเกราะทองกับผ้าคลุมฟ้า, Spear มีหมวกพร้อมพู่แดง, Axe มีหมวกเขาและเครา, Dagger ใส่ฮูดและผ้าปิดหน้า ส่วนชื่อดีไซน์ยังเหมือนเดิม และมอนมี 3 แบบตามชื่อ (Mossling / Crypt Sentinel / Cave Stalker) ตารางด้านล่างคือดีไซน์รุ่นก่อน

อัปเดตตามภาพอ้างอิงล่าสุด: ตัวละครพิกเซลสัดส่วน chibi หัวใหญ่ เห็นใบหน้า ชุดและอาวุธต่างกันชัดเจน ภาพสร้างด้วยโค้ดต้นฉบับ ไม่คัดลอก sprite จากภาพอ้างอิง

`src/game/HeroArt.ts` เก็บ pixel geometry ร่วมกัน ใช้สร้างทั้ง texture ใน Phaser และ SVG ในหน้าต่างเลือกคลาส/รายชื่อตัวละคร/รูปโปรไฟล์ จึงไม่ใช่เพียงภาพตัวอย่างแยกจากตัวละครในเกม คลิกภาพโปรไฟล์หรือ Character → View all five character designs เพื่อดูครบทุกอาชีพ เซฟเก่าคงคลาสเดิมและใช้รูปลักษณ์ใหม่โดยอัตโนมัติ

ตัวละครเดิน หันหน้า และโจมตีตามอาวุธ: Sword ฟัน, Spear แทง, Wand ยิงเวท, Axe เหวี่ยงหนัก, Dagger ฟันเร็ว สัตว์เลี้ยงเดินตาม

## ลำดับห้อง

1. ขณะมีศัตรู ประตูทางออกปิดอยู่
2. เมื่อศัตรูตัวสุดท้ายตาย เริ่มช่วงข้ามห้อง 6.5 วินาที
3. ประตูแยกเปิด ตัวละครเดินไปทางออก ผ่านทางเชื่อมเข้าห้องข้างเคียง กล้องเคลื่อนตาม และสัตว์เลี้ยงตามหลัง
4. เมื่อเดินถึงห้องถัดไป จึงเพิ่มหมายเลขห้องและสร้างศัตรูใหม่

เวลาและการเกิดศัตรูควบคุมโดย core (`RoomTraversal.ts`, `CombatEngine.ts`) ไม่รอ acknowledgement จาก renderer พิกัดเดินเป็น presentation ที่อิงเวลาเดียวกัน ไม่ได้เพิ่มระบบควบคุมเดินหรือ pathfinding อิสระ

ใช้ฉากสามส่วนหมุนเวียนในพิกัดโลกเพื่อให้เดินต่อเนื่องและจำกัดจำนวนวัตถุฉาก หลังบอสจะเดินไปห้องแรกของภูมิภาคถัดไปตามกฎเดิม การตายและ fast travel ยังคงใช้การกลับจุดเริ่มต้น ไม่แสดงเป็นการเดินผ่านประตู

ช่วงข้ามห้องเพิ่มจากเดิม 1.3 เป็น 6.5 วินาที อัตราเคลียร์สดจะช้าลงตามเวลาที่ใช้เดินจริง ประวัติ AFK ใหม่รวมช่วงนี้ในระยะเวลาการเล่นด้วย
