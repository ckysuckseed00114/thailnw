## 1. ภาพรวมทิศทางงานศิลป์ใหม่ (New Art Direction)

ในเกมต้นฉบับ ตัวละครและมอนสเตอร์ใช้สไตล์พิกเซลแบบ Chibi ขนาดเล็ก (16x16 หรือ 32x32) ทำให้รายละเอียดของเกราะและอาวุธระดับสูงมองเห็นได้ยาก การออกแบบใหม่นี้จะปรับไปสู่ **High-Definition Stylized 2D (HD-2D / Dark Fantasy Comic Art)** คล้ายสไตล์เกมอย่าง *Hades*, *Dead Cells*, หรือ *Solo Leveling*:
- **Silhouette เด่นชัด:** แต่ละคลาสมีรูปทรงและท่วงท่าเฉพาะตัว จดจำได้ทันทีจากระยะไกล
- **Dynamic Rim Light:** แสงสะท้อนขอบตัวละครตามสีของแสงไฟในดันเจี้ยน (เช่น แสงไฟสีม่วงใน Obsidian Sanctum หรือแสงไฟสีส้มจากคบเพลิง)
- **VFX Particle Integration:** สกิลและอาวุธระดับสูงมีเอฟเฟกต์แสง แสงประกายไฟ ประกายสายฟ้า และควันวิญญาณไหลเวียน

## 2. การออกแบบ 5 สายอาชีพ (Hero Classes Redesign)

### ⚔️ 1. Sword (Paladin / Vanguard)
- **คอนเซปต์:** อัศวินเกราะหนักศรัทธาแห่งแสงสว่าง
- **อาวุธ & อุปกรณ์:** ดาบใหญ่จารึกอักขระรูนเรืองแสงสีฟ้าคราม (Runic Greatsword) พร้อมโล่ตราหัวสิงโตทองคำเคลือบขอบออบซิเดียน (Lion Crest Tower Shield)
- **เอกลักษณ์ภาพ:** เกราะแผ่นหนาหรูหราสีดำ-ทอง ผ้าคลุมหลังสีน้ำเงินเข้มขลิบทอง หมวกเกราะปิดมิดมีมงกุฎแสง
- **แอนิเมชันสกิล Whirlwind:** ควงดาบ 360 องศา เกิดเป็นพายุใบมีดแสงสีทองประกายหมุนรอบตัว

### 🪄 2. Wand (Arcane / Astral Mage)
- **คอนเซปต์:** จอมเวทสาวแห่งดวงดาวและเปลวเพลิงโบราณ
- **อาวุธ & อุปกรณ์:** คทาคริสตัลเปลวเพลิงลอยตัว (Floating Crystal Staff) ปลายยอดลุกเป็นไฟศักดิ์สิทธิ์
- **เอกลักษณ์ภาพ:** เสื้อคลุมสีน้ำเงินครามลวดลายแผนที่ดวงดาวสีทอง (Constellation Robe) ผ้าคลุมศีรษะลึกลับ ดวงตาส่องประกายแสงเวทมนตร์
- **แอนิเมชันสกิล Fireball:** ร่ายลูกไฟยักษ์ระเบิดเป็นละอองดาวเมื่อกระทบเป้าหมาย

### 🗡️ 3. Dagger (Shadow Assassin)
- **คอนเซปต์:** นักฆ่าเงาแห่งรัตติกาล
- **อาวุธ & อุปกรณ์:** มีดสั้นคู่พลังวิญญาณสีม่วง (Twin Phantom Daggers) ที่มีควันไอวิญญาณระเหยออกมาตลอดเวลา
- **เอกลักษณ์ภาพ:** ชุดเกราะหนังรัดรูปสีม่วงเข้ม-ดำ ผ้าคลุมพร้อมฮู้ดปิดบังใบหน้า เน้นความคล่องแคล่วและล่องหน
- **แอนิเมชันสกิล Shadow Step:** กลายสภาพเป็นละอองเงาสีม่วงวาบไปด้านหลังเป้าหมาย แล้วแทงไขว้เกิดรอยแผลมิติ

### 🪓 4. Axe (Magma Berserker)
- **คอนเซปต์:** นักรบคลั่งผู้ถือครองพลังเพลิงลาวาใต้พิภพ
- **อาวุธ & อุปกรณ์:** ขวานยักษ์มังกรลาวา (Colossal Magma Battleaxe) ใบมีดเป็นหินภูเขาไฟที่มีรอยแตกไหลเป็นลาวาร้อนระอุ
- **เอกลักษณ์ภาพ:** หัวกะโหลกมังกรเป็นสนับไหล่ ผิวหนังมีรอยสักเส้นเลือดเพลิงเรืองแสงสีส้มแดง ผมเคราดุดัน
- **แอนิเมชันสกิล Cleave:** กระโดดฟันขวานลงพื้นอย่างรุนแรงจนพื้นหินแตกแยก มีเสาไฟพวยพุ่งขึ้นมาสตันศัตรู

### ⚡ 5. Spear (Valkyrie Dragoon)
- **คอนเซปต์:** นักรบหอกสายฟ้าปีกเงิน
- **อาวุธ & อุปกรณ์:** หอกเกล็ดมังกรประจุสายฟ้าสีฟ้าสด (Crackling Lightning Spear)
- **เอกลักษณ์ภาพ:** ชุดเกราะเงินขัดเงาพร้อมปีกคู่ Valkyrie บนหมวกเกราะ ผ้าคลุมสั้นสีน้ำเงินพริ้วไหว
- **แอนิเมชันสกิล Pierce:** รวมสายฟ้าไว้ที่ปลายหอกแล้วพุ่งทะลวงเป็นลำแสงเลเซอร์ทำลายล้างศัตรูเป็นแนวยาว

## 3. การออกแบบสัตว์เลี้ยงคู่หู (Pets Redesign)

สัตว์เลี้ยงถูกออกแบบให้มีความน่ารัก (Cute) ควบคู่กับความดุดัน (Mystical / Powerful):

1. **Emberkit (จิ้งจอกเพลิง):** 
   - รูปลักษณ์คล้ายจิ้งจอกภูตไฟ ขนเป็นเปลวเพลิงไล่เฉดส้ม-ทอง หางฟูฟ่องส่องสว่างนำทางในความมืด 
   - สกิล: พ่นกระสุนไฟ Ember Bolt โจมตีศัตรูระยะไกล
2. **Leafhopper (ภูตกระต่ายพฤกษา):**
   - ภูตตัวจิ๋วมีปีกโปร่งแสงคล้ายใบไม้ ลอยตัวอยู่ข้างตัวละคร
   - สกิล: ปล่อยออร่าละอองเกสรเขียวมรกตช่วยฟื้นฟูเลือด (Heal)
3. **Shellby (เต่าหินผลึกแก้ว):**
   - เต่าหินโบราณ กระดองเป็นผลึกคริสตัลอัญมณีสีฟ้า มีไอเวทมนตร์แผ่ออกมา
   - สกิล: สร้างเกราะโดมบาเรียผลึกแก้วป้องกันการโจมตีครั้งถัดไป
4. **Craboulder (ปูโกเลมหินลาวา):**
   - โกเลมปูหินภูเขาไฟ ก้ามทั้งสองข้างแข็งแกร่งดุจค้อนหิน
   - สกิล: กลิ้งตัวหรือทุบก้อนหินสตันศัตรู

## 4. ระบบการแสดงผลออร่าและระดับไอเทม (Visual Progression & Equipment Auras)

เพื่อสร้างความรู้สึกถึงพลังและความคุ้มค่าในการฟาร์ม ตัวละครจะเปลี่ยนรูปลักษณ์ตามเกียร์ที่สวมใส่:

| ระดับความหายาก | เอฟเฟกต์บนตัวละครและอาวุธ |
| :--- | :--- |
| **Common (เทา)** | อาวุธเหล็กธรรมดา เกราะหนังหรือเหล็กด้าน ไร้แสงประกาย |
| **Uncommon (เขียว)** | รอยสลักบางๆ มีประกายไอเวทมนตร์สีเขียวจางๆ |
| **Rare (ฟ้า)** | คมดาบคมกริบเรืองแสงสีฟ้า มีไอเย็นหรือประกายไฟฟ้าเล็กน้อย |
| **Epic (ม่วง)** | มีออร่าสีม่วงไหลเวียนตามแนวอาวุธ โล่มีตราสัญลักษณ์เรืองแสง |
| **Legendary (ทอง)** | ตัวละครมีละอองทองลอยรอบตัว อาวุธมีประกายเปลวไฟสีทอง |
| **Mythic (แดง/รุ้ง)** | **Full Celestial Aura:** มีปีกพลังงานหรือวงแหวนรูนลอยอยู่ด้านหลัง อาวุธลุกเป็นไฟหรือพายุสายฟ้าแบบไดนามิก |

## 5. การจำลองภาพในเกมจริง (In-Game Battle Presentation)

เมื่อนำงานศิลป์ใหม่ไปเรนเดอร์ในดันเจี้ยนจริง จะเกิดบรรยากาศที่เหนือกว่าแบบเดิมอย่างชัดเจน:
- **มุมมอง:** Isometric 2.5D หรือ Top-Down พร้อมระบบกล้อง Dynamic Zoom เมื่อใช้สกิลใหญ่
- **แสงเงาในฉาก:** กำแพงหินและพื้นกระเบื้องสะท้อนแสงไฟจากคบเพลิงสีม่วงตามเสา มีเงาทอดยาว
- **การต่อสู้:** ตัวเลขดาเมจลอยเด่นชัด (สีขาวสำหรับการโจมตีปกติ, สีทองประกายพร้อมแท็ก `CRIT!` สำหรับคริติคอล)
- **ระบบสัตว์เลี้ยง:** สัตว์เลี้ยงเดินและโจมตีเคียงข้างอย่างเป็นธรรมชาติ เช่น Emberkit พ่นลำแสงไฟไปที่ก็อบลิน
- **HUD & อินเทอร์เฟซ:** แถบเลือดหัวใจสีแดงคมชัด, หลอดพลังงานมานาสีฟ้า, ตัวนับคอมโบสีฟ้าสด (`X14 HITS!`), และมินิแมปเรดาร์มุมขวาล่าง

## 6. สเปกชีตสไปรต์และการเรนเดอร์ใน Phaser 3 (Technical Sprite Specs)

เพื่อให้ทีมพัฒนาและ Codex นำไปต่อยอดในโค้ด Phaser 3 ได้ทันที:

### โครงสร้าง Spritesheet (Frame Size: 128x128 px)
```typescript
export const HERO_ANIMATION_CONFIG = {
  frameWidth: 128,
  frameHeight: 128,
  animations: {
    idle: { start: 0, end: 5, frameRate: 8, repeat: -1 },
    run: { start: 6, end: 13, frameRate: 12, repeat: -1 },
    attack: { start: 14, end: 19, frameRate: 14, repeat: 0 },
    skill: { start: 20, end: 27, frameRate: 16, repeat: 0 },
    hit: { start: 28, end: 30, frameRate: 10, repeat: 0 },
    die: { start: 31, end: 36, frameRate: 8, repeat: 0 }
  }
};
```

### การตั้งค่า Shader & Lighting ใน Phaser 3
```typescript
// ใน CatacombScene.ts
const lights = this.lights.enable();
this.lights.setAmbientColor(0x1a1a2e); // แสงบรรยากาศมืดสลัว

// เพิ่มแสงคบเพลิงสีม่วงตามผนัง
this.lights.addLight(torchX, torchY, 200).setColor(0xa855f7).setIntensity(2.5);

// เพิ่มแสงออร่ารอบตัวฮีโร่และสัตว์เลี้ยง Emberkit
const heroLight = this.lights.addLight(hero.x, hero.y, 150).setColor(0xfbbf24).setIntensity(1.8);
const petLight = this.lights.addLight(pet.x, pet.y, 100).setColor(0xf97316).setIntensity(2.0);
```
