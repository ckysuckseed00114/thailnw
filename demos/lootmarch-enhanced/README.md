# LootMarch Enhanced (standalone demo)

Prototype UI + 2D canvas combat mock **without** the Embermarch core engine. Use it to preview layout, hotkeys, and Web Audio feedback.

Open **`index.html`** in a browser (double-click or drag into Chrome/Edge). No build step required.

Integrated into the main game:

- Web Audio combat feedback → `src/services/SoundFX.ts`
- Immersive Phaser scene → `src/game/scenes/CatacombScene.ts`
